# Ice Bear Dashboard

A personal beginner frontend project inspired by a classic dashboard layout. This project was built to practice HTML structure, CSS styling, and JavaScript DOM generation while creating something visually clean and playful.

## Project Overview

This dashboard includes:

- A left sidebar navigation panel
- A top header with search, notifications, and user profile details
- Action buttons like New, Upload, and Share
- A content section with article cards
- An announcements and trending sidebar
- A playful theme using custom icons, profile images, and a friendly bear-themed design

The project is intentionally simple and beginner-friendly, making it a good example of layout building and frontend fundamentals.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## What I Practiced

This project helped practice:

- Structuring a webpage with semantic HTML
- Using CSS Grid and Flexbox for layout
- Styling reusable UI components
- Writing JavaScript to generate repeated content dynamically
- Organizing assets and files in a clean project structure


## Design Notes

The project uses a custom dashboard style with:

- a dark blue sidebar
- a light blue content background
- strong accent colors for action buttons
- a cartoon-like bear theme for a more personal aesthetic

## JavaScript Behavior

The script file dynamically creates the article cards in the main content area. This is a nice beginner example of using arrays of data and generating repeated HTML elements with JavaScript.
